# Claude Code mods

A Claude Code plugin marketplace with mods by Lukas Hinterleitner.

| Mod | What it does |
| --- | --- |
| [usage-meter](plugins/usage-meter) | Live usage meter under the prompt: context fill, rate-limit windows, session cost and token totals |

## Install a mod

At the prompt of a Claude Code terminal session:

```
/plugin install <mod> --marketplace lukas-hinterleitner/claude-code
```

For example, `/plugin install usage-meter --marketplace lukas-hinterleitner/claude-code`.
Answer `y` to add the marketplace, then pick a scope.
